FM1 Time-Signal Source

An M-VAVE FM1 synthesizer repurposed as a WWV-style time-signal station for an AM/SSB transmitter, keeping Haida Standard Time (UTC−08:48) for amateur station VA7BFR: second ticks, minute markers, standard tones, and a spoken announcement each minute.

Flash firmware Update page with this build embedded, plus a simulator of the station panel. Turn on the simulator's sound and it keeps time from your computer's clock. Clip collector Record a language's announcement clips into a local checkout's speech/ folder.
Before flashing
  • Back up any data on the device; firmware defects may cause data loss.
  • Use Chrome or Edge (Web MIDI) with the FM1 connected over USB.
  • Afterwards, set the clock with tools/station.py sync. If the station has no speech bank, upload one: tools/station.py upload speech-bank-en.bin.

Downloads: FM1_OFFICIAL_OPEN.fwsc · speech-bank-en.bin · SHA256SUMS.txt

The speech bank is English in a placeholder text-to-speech voice (Piper en_US-john-medium, trained on public-domain recordings), built from this commit's speech/en/clips.tsv.
